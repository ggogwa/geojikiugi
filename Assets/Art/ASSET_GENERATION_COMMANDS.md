# 거지키우기 × 부동산 × 자동전투 — 추가 에셋 생성 명령문

## 공통 제작 규칙

아래 명령문은 이미지 생성 도구에 한 블록씩 입력한다. 캐릭터와 아이콘은 생성 후 배경 제거를 위해 `#ff00ff` 단색 배경을 사용한다. 모든 결과물은 글자, 숫자, 워터마크 없이 제작한다.

공통 스타일 문구:

```text
캐주얼 심플 2D 모바일 게임 일러스트, 도트 아님, 고퀄 리얼 아님, 둥근 형태, 굵고 일정한 남색 외곽선, 부드러운 셀 셰이딩, 선명한 실루엣, 작은 화면에서도 식별 가능, 현재 개복치 성장 에셋과 동일한 채도와 광택, 글자와 숫자와 워터마크 없음.
```

## 1. 거지 클리커 캐릭터 5단계

출력 파일 권장: `BeggarProgress_5Stages.png`

```text
현재 게임용 거지 캐릭터의 재산 성장 5단계 스프라이트 시트를 제작해. 정확히 5열 1행, 정면 3/4 시점, 동일한 자세와 기준선. 1단계는 해진 옷과 빈 깡통, 2단계는 깨끗한 헌옷, 3단계는 평범한 캐주얼 복장, 4단계는 작은 정장과 서류가방, 5단계는 고급 정장과 금색 지팡이. 미니 프로포션, 표정은 가난함에서 자신감으로 점진 변화. 배경은 완전히 균일한 #ff00ff, 그림자 없음, 각 단계가 겹치지 않게 충분한 여백. [공통 스타일 문구]
```

## 2. 부동산 6등급 건물

출력 파일 권장: `EstateBuildings_6Tiers.png`

```text
부동산 6등급 건물 아이콘 스프라이트 시트를 제작해. 정확히 3열 2행. 순서는 원룸, 투룸 주택, 소형 상가, 오피스텔, 꼬마 빌딩, 랜드마크 타워. 동일한 아이소메트릭 3/4 시점과 바닥 기준선, 등급이 오를수록 높이와 창문 수와 장식이 증가. 건물 전체가 잘리지 않아야 함. 배경은 완전히 균일한 #ff00ff, 바닥과 그림자 없음. [공통 스타일 문구]
```

## 3. 전투 아군 — 역할 × 속성 12종

출력 파일 권장: `BattleHeroes_12.png`

```text
자동전투용 미니 영웅 12종 스프라이트 시트를 제작해. 정확히 4열 3행. 행은 탱커, 딜러, 힐러. 열은 불, 물, 풀, 무속성. 모든 캐릭터는 왼쪽을 바라보는 3/4 전투 자세와 같은 크기. 탱커는 큰 방패와 높은 체격, 딜러는 검과 민첩한 체격, 힐러는 지팡이와 작은 가방. 불은 주황-빨강, 물은 파랑-청록, 풀은 초록-연두, 무속성은 회색-금색 포인트. 별 등급 표시는 넣지 말 것. 배경은 완전히 균일한 #ff00ff, 그림자 없음. [공통 스타일 문구]
```

## 4. 보스 10스테이지

```text
자동전투 보스 10종 성장 스프라이트 시트를 제작해. 정확히 5열 2행, 스테이지 1부터 10까지 좌우 순서. 모두 오른쪽을 바라보는 3/4 전투 자세. 1~3은 골목 불량배와 작은 괴물, 4~6은 갑옷 괴물과 부동산 침입자, 7~9는 거대 정령과 금고 파괴자, 10은 왕관을 쓴 거대 최종 보스. 속성 순환은 불, 물, 풀, 무이며 색과 이펙트로 명확히 구분. 단계가 오를수록 실루엣과 장비가 강해지되 셀 안에서 잘리지 않게 배치. 배경은 완전히 균일한 #ff00ff, 그림자 없음. [공통 스타일 문구]
```

## 5. 세로형 배경 3종

각 배경은 별도로 생성한다. 권장 크기 `1080×1920`.

### 본부 골목

```text
1080×1920 세로 모바일 게임 본부 배경. 따뜻한 낮의 한국풍 골목, 낡은 상점과 작은 원룸 건물, 중앙과 상하단은 UI가 올라가도록 시각적 디테일을 낮추고 가장자리만 장식. 캐릭터, 글자, 버튼 없음. [공통 스타일 문구]
```

### 개복치 어항

```text
1080×1920 세로 모바일 게임 개복치 패널 배경. 밝은 실내의 둥근 유리 어항, 맑은 청록색 물, 작은 수초와 조약돌, 중앙은 개복치 스프라이트를 올릴 수 있도록 비워 둠. 물고기, 글자, 버튼 없음. [공통 스타일 문구]
```

### 전투장

```text
1080×1920 세로 모바일 자동전투 배경. 아래쪽은 아군 3명이 서는 도시 옥상, 위쪽은 보스가 서는 공간, 중앙에 전투 거리 확보. 밤의 도시 조명, UI가 읽히도록 낮은 대비. 캐릭터, 몬스터, 글자, 버튼 없음. [공통 스타일 문구]
```

## 제작 우선순위

1. 거지 5단계
2. 부동산 6등급
3. 전투 아군 12종
4. 보스 10종
5. UI 아이콘
6. 전투 이펙트
7. 세로형 배경

스프라이트 시트 생성 후에는 셀별 PNG로 분리하고 Unity Import Settings를 `Sprite (2D and UI)`, `Single`, `Alpha Is Transparency`, `Mip Maps Off`로 설정한다.
