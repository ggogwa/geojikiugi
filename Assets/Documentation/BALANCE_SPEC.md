# 3시간 완주 밸런스 명세

실제 런타임 수치는 `Assets/Resources/Config/game_balance.json`에서 관리한다. 기획 수치 변경 시 C# 코드를 수정하지 않고 해당 JSON을 편집한다.

## 완주 정의

- 스테이지 10 보스 최초 격파
- 랜드마크 타워 1채 매입
- 예상 플레이 시간: 적극 플레이 150~180분, 보통 플레이 약 180분

## 권장 플레이 동선

| 구간 | 목표 시간 | 핵심 행동 | 도달 목표 |
|---|---:|---|---|
| 거리 생활 | 0~15분 | 구걸, 첫 개복치 매입, 원룸 매입, 1성 파티 구성 | Stage 2 |
| 자립 기반 | 15~45분 | 개복치 Lv.3~5 매각, 주택·소형 상가 매입 | Stage 3~4 |
| 성장 전환 | 45~100분 | 속성 파티 정비, 오피스텔 매입, 최초 클리어 보상 활용 | Stage 5~7 |
| 자산 확장 | 100~160분 | 고등급 고용, 꼬마 빌딩 매입, 반복 수익 축적 | Stage 8~10 |
| 완주 | 160~180분 | Stage 10 격파, 랜드마크 타워 매입 | 게임 완료 |

## 조정 가능한 수치

### 경제

- 시작 자금: 1,000원
- 시작 누적 획득액: 0원
- 부동산 기본 가격: 2,500 / 15,000 / 75,000 / 300,000 / 950,000 / 2,800,000원
- 부동산 초당 수익: 5 / 30 / 140 / 520 / 1,800 / 6,000원
- 부동산 해금 스테이지: 1 / 2 / 3 / 5 / 7 / 10
- 동일 부동산 추가 매입 가격 증가율: 보유 1채당 25%
- 생활복 누적 획득액 기준: 0 / 10,000 / 75,000 / 350,000 / 1,500,000원
- 구걸 수익: 생활복 레벨 × 15원

### 개복치 강화·판매

- 매입가: 500원
- Lv.1~9 강화비: 180 / 300 / 500 / 800 / 1,300 / 2,100 / 3,400 / 5,500 / 9,000원
- Lv.1~10 매각가: 500 / 800 / 1,300 / 2,200 / 3,800 / 6,800 / 12,500 / 24,000 / 48,000 / 100,000원
- Lv.1~9 실패율: 5 / 8 / 11 / 14 / 18 / 22 / 27 / 33 / 40%
- 실패 결과: 개복치 소멸, 투자금 회수 없음

### 고용시장

- 별 등급 확률: 1성 58%, 2성 30%, 3성 12%
- 고용비: 별당 500원
- 기본 리롤비: 100원
- 같은 세션 내 리롤 증가액: 회당 50원
- 탱커 기본 HP: 별당 520
- 딜러·힐러 기본 HP: 별당 230
- 딜러 공격력: 별당 72
- 탱커 공격력: 별당 12
- 힐러 회복량: 별당 58

### 전투

- 보스 HP: 800 + 스테이지 × 500
- 보스 공격력: 28 + 스테이지 × 9
- 영웅 공격 주기: 0.9초
- 보스 공격 주기: 1.45초
- 유리 속성 배율: 1.5배
- 불리 속성 배율: 0.5배
- 동일 속성 2인 시너지: 1.5배
- 동일 속성 3인 시너지: 2.0배
- 최초 클리어 보상: 3,000 + 스테이지 × 2,000원
- 반복 클리어 보상: 400 + 스테이지 × 200원

## 설계 의도

부동산은 약 8~11분의 회수 기간을 기본으로 하며, 스테이지 해금으로 다음 목표를 명확히 한다. 전투 최초 보상은 진행 촉진용, 반복 보상은 보조 수입으로 제한한다. 개복치는 고레벨로 갈수록 실패율과 기대 보상이 함께 커져 중간 매각과 고위험 도전 사이의 선택이 생기도록 한다.
