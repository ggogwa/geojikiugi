# Beggar Tycoon 전면 아트 리소스 교체 명세

## 1. 목표와 핵심 방향

- 기준 해상도: 세로형 모바일 `390 × 844`, 원화 작업 기준 `1080 × 1920`
- 목표 인상: 밝고 정돈된 캐주얼 카툰, 두꺼운 외곽선, 단순한 면 분할, 높은 정보 가독성
- 홈/부동산: 따뜻한 크림색 바탕과 노란 포인트
- 전투: 짙은 남색 바탕과 금색 포인트, 산호색 HP, 초록색 고용 버튼
- 부동산 참고 이미지의 아이소메트릭 구도는 유지하되 픽셀 아트 질감은 사용하지 않는다. 거지 캐릭터와 동일한 `깔끔한 외곽선 + 2단 셀 채색`으로 다시 그려 화면 전체의 화풍을 통일한다.
- 참고 이미지의 워터마크, 생성 흔적, 자잘한 왜곡은 실제 리소스에 포함하지 않는다. 모든 결과물은 투명 배경 또는 명세된 단색 배경으로 신규 제작한다.
- UI 텍스트는 이미지에 굽지 않고 Unity 텍스트 컴포넌트로 표시한다.

## 2. 스타일 바이블

### 형태와 채색

| 항목 | 제작 기준 |
|---|---|
| 외곽선 | 기준 1024px 캐릭터에서 6~10px, 진갈색 또는 짙은 남색. 순수 검정은 최소화 |
| 채색 | 기본색 + 그림자 1단 + 제한적인 하이라이트 1단 |
| 그림자 | 광원은 좌측 상단으로 통일, 흐린 에어브러시보다 단정한 면 그림자 사용 |
| 모서리 | UI는 12~20px 라운드, 건물은 직선 구조에 둥근 장식 요소 혼합 |
| 재질 | 반사·실사 질감 금지. 목재, 천, 금속도 색면과 작은 하이라이트로 표현 |

### HUD와 상태 표시

- 재화 캡슐: 코인 아이콘, 금액, 증가 애니메이션 영역
- 초당 수익 캡슐: `+/sec` 아이콘과 숫자 영역
- 구걸 진행 바: 프레임, 채움, 임계점 마커, 반짝임 오버레이
- 전투 HP 바: 프레임, 산호색 채움, 피격 플래시
- 스테이지 진행 바: 1~20 구간형 또는 현재/최대 숫자형
- 등급 배지: 1~5성, 별 1개 아이콘 반복 배치를 기본으로 함
- 상태 배지: 잠김, 구매 가능, 보유, 최대, 최초 클리어, 반복 보상
- 숫자 상승 플로터 배경 2종: 코인 획득, 피해/회복

### 공통 아이콘

최소 `128×128`, 투명 PNG, 외곽선 두께와 내부 여백을 통일한다.

- 개복치, 코인, 초당 수익, 구걸, 부동산, 전투, 설정, 뒤로가기
- 잠금, 보유, 구매, 매각, 업그레이드, 정보, 닫기
- 탱커, 딜러, 힐러, 보스, 주사위, 리롤, 트로피
- 불, 물, 풀, 무속성
- 공격, 방어, 체력, 회복, 속도, 광폭화
- 최초 보상, 반복 보상, 자동 전투, 포기

## 4. 구걸 화면과 거지 캐릭터

### 캐릭터 모델 원칙

- 은회색 머리, 창백한 피부, 회갈색 누더기 의상을 핵심 식별 요소로 유지한다.
- SD 비율은 2.5~3등신. 큰 머리와 눈, 작은 손발을 사용하되 지나치게 유아적으로 만들지 않는다.
- 참고 이미지처럼 우울한 기본 표정을 사용하고 클릭 반응에서 감정 폭을 크게 만든다.
- 캔버스와 피벗은 모든 상태에서 동일하게 유지한다. 피벗은 `Bottom Center`.
- 배경색은 포함하지 않으며 투명 PNG로 납품한다.

### 성장 단계 5종

| 단계 | 외형 변화 | 필수 소품 |
|---|---|---|
| T01 무일푼 | 낡은 누더기, 맨발, 흐트러진 머리 | 빈 깡통 |
| T02 거리 생활자 | 누더기 보수, 낡은 신발 | 동전 든 깡통 |
| T03 자립 시작 | 중고 후드/재킷, 정돈된 머리 | 작은 가방 |
| T04 성공 직전 | 단정한 캐주얼, 건강한 안색 | 지갑/휴대폰 |
| T05 성공가 | 깔끔한 코트 또는 수트, 자신감 있는 자세 | 금색 장식 소품 |

각 단계별 필수 출력:

- `Idle` 기본 전신 1종
- 클릭 반응 5종: `Happy / Surprised / Desperate / Grateful / Cheeky`
- 눈 깜빡임 2프레임과 입 모양 3종을 별도 레이어로 제공
- 마스터 원본: 머리, 얼굴, 몸, 팔, 소품, 그림자 분리 PSD 또는 Clip Studio 파일
- PNG 출력: 상태당 `1024×1024`, 동일 바운딩 박스

완성형 기준 캐릭터 출력은 `5단계 × 6상태 = 30장`이다. 1차 적용은 T01의 6상태와 T02~T05 Idle 4장을 우선 제작할 수 있다.

### 구걸 화면 배경/연출

- 거리 배경 3종: 골목, 상점가, 번화가. 성장 단계에 따라 순차 교체
- 중경 오브젝트: 벤치, 가로등, 화분, 간판, 상점 창문
- 전경 오버레이: 나뭇잎, 먼지, 빛 알갱이
- 클릭 위치 코인 3종: 정면, 측면, 반짝이는 희귀 코인
- 코인 파티클 6프레임, 반짝임 4프레임, 클릭 링 4프레임
- 말풍선 3종: 일반, 기쁨, 당황. 문구는 Unity 텍스트로 표시
- 캐릭터 하단 타원 그림자 1종

## 5. 부동산 3×2 타일맵

### 구현 권장안

현재 화면은 고정된 6개 부동산을 표시하므로 실제 Unity Tilemap보다 `고정 아이소메트릭 베이스 + 6개 건물 오버레이` 방식이 적합하다. 타일맵처럼 보이면서 각 부지를 독립적으로 잠금/구매/보유 처리할 수 있고 모바일 UI의 클릭 영역도 안정적이다.

### 화면 구성

- 기준 캔버스: `1024×768` 투명 또는 크림 배경
- 배열: 3열 × 2행, 아이소메트릭 도로가 각 부지를 연결
- 각 부지 클릭 영역은 시각적 경계보다 12% 넓게 설정
- 구매 전에는 건물을 흐리게 보여주지 않고 `빈 부지 + 작은 설계도 실루엣`을 표시한다.
- 구매 시 딤과 공사 가림막이 걷히고 완성 건물이 아래에서 위로 나타난다.
- 카드에는 가격과 초당 획득 금액만 상시 표시한다. 구매 가능/불가 문구는 표시하지 않는다.

### 베이스 타일 세트

2:1 아이소메트릭 기준 타일 `256×128`, 아틀라스 `2048×2048`.

- 잔디 3변형, 흙 2변형, 빈 부지, 기초 공사
- 도로 직선 2방향, 코너 4방향, T자 4방향, 교차로
- 보도 직선/코너, 연석, 횡단보도
- 생울타리 직선/코너/끝, 낮은 담장, 펜스
- 나무 3종, 관목 3종, 꽃 3종, 가로등, 우편함, 벤치
- 부지 선택 테두리, 클릭 하이라이트, 보유 금색 테두리
- 구름 그림자와 환경광 오버레이

### 부동산 6종

| ID | 건물 콘셉트 | 실루엣 기준 |
|---|---|---|
| E01 | 단칸방/원룸 | 낮고 작은 주택, 파란 지붕 |
| E02 | 다세대 주택 | 2~3층, 반복 창문 |
| E03 | 상가 주택 | 1층 점포 간판, 2층 주거 |
| E04 | 소형 빌딩 | 세로형 4~5층, 옥상 설비 |
| E05 | 고급 아파트 | 넓은 단지형, 조경과 입구 |
| E06 | 랜드마크 타워 | 가장 높은 실루엣, 금색 포인트 |

건물별 납품 상태:

- `Blueprint`: 구매 전 설계도/표지판
- `Construction`: 구매 순간 짧게 표시할 공사 상태
- `Owned`: 완성 상태
- `Owned_Glow`: 구매 완료 연출용 금색 빛 오버레이
- 투명 PNG `768×768`, 동일 바닥 접점 및 `Bottom Center` 피벗

추가 출력:

- `EstateMap_Base_3x2.png`
- `EstatePlot_01~06_Empty.png`
- `EstatePlot_01~06_HitAreaGuide.png`는 개발 가이드용이며 빌드에는 포함하지 않음
- 자동차 3종, 시민 4종, 새/고양이 각 1종의 소형 루프 장식

## 6. 전투 화면

### 배경과 보스

- 전투 배경 5종: 뒷골목, 시장, 공사장, 도심 옥상, 금융 타워
- 각 배경은 일반/보스 조명 2변형, `1080×900`
- 20스테이지는 보스 원화 10종 + 강화형 변형 10종으로 구성한다.
- 강화형은 단순 색상 변경이 아니라 무기, 어깨 장식, 상처, 광폭화 오라를 추가한다.
- 보스 전신은 `1024×1024`, 투명 PNG, 동일 바닥 피벗
- 상태: Idle, Hit, Enrage, Defeated 최소 4종

### 영웅

- 역할 3종 × 속성 4종 = 12명
- 역할 실루엣: 탱커는 넓고 낮게, 딜러는 전방 기울기, 힐러는 둥글고 열린 자세
- 성급 1~5는 캐릭터 색을 바꾸지 않고 카드 프레임, 별, 후광 강도로 구분한다.
- 캐릭터 전신 `768×768`, 초상화 `512×512`, 투명 PNG
- 카드 프레임: 1~2성 회색, 3성 청색, 4성 자색, 5성 금색

### 전투 VFX

- 기본 타격, 강타, 방패 충돌, 화염 베기, 물결, 가시, 무속성 충격
- 회복, 보호막, 치명타, 광폭화, 처치, 승리
- 각 효과 6~12프레임, 기준 `512×512` 스프라이트 시트
- 화면 플래시 오버레이: 피격 빨강, 회복 초록, 보스 광폭화 주황

## 7. 홈 진행 배경과 개복치

- 성장 구간 배경 7종은 거리에서 성공한 도시 생활로 자연스럽게 이어지도록 제작한다.
- 배경은 캐릭터보다 채도와 대비를 15~25% 낮춰 전경 가독성을 확보한다.
- 개복치 10단계는 크기만 확대하지 않고 장식, 표정, 등급 테두리로 단계 차이를 만든다.
- 개복치 출력 `768×768`, 투명 PNG, 동일 피벗
- 매입/매각 연출 아이콘과 희귀 성공 후광을 별도 제공한다.

## 8. 파일명과 기존 경로 교체 규칙

코드 변경을 줄이기 위해 현재 `Resources/GameArt` 경로와 주요 파일명을 유지한다.

| 대상 | 유지할 경로/규칙 |
|---|---|
| 거지 성장 | `Beggar/Beggar_Stage_01~05` |
| 클릭 표정 | `Beggar/Reactions/01_Happy~05_Cheeky` |
| 부동산 | `Estate/Estate_01_Studio~Estate_06_Tower` |
| 영웅 | `Heroes/Hero_{Role}_{Element}` |
| 공통 아이콘 | `Icons/Icon_{Purpose}` |
| UI 패널/버튼 | `UI/UI_{Type}_{Variant}` |
| 홈 배경 | `Backgrounds/HomeProgress/Background_Home_00~06` |
| 보스 | `Bosses/Boss_01_Final~Boss_20_Final` |

현재 10종 보스를 11~20 스테이지에서 재사용하는 구조라면 신규 20종 경로를 읽도록 로딩 로직을 함께 수정해야 한다. 단, 제작비 절감형으로는 01~10 원본에 `Elite` 장식 오버레이 10종을 조합할 수 있다.

## 9. 납품 형식과 Unity 임포트

- 원본: 레이어가 정리된 PSD, PSB 또는 Clip Studio 파일
- 출력: PNG-24 RGBA, sRGB, Straight Alpha
- UI/캐릭터: Sprite (2D and UI), Mipmap Off, Mesh Type Full Rect
- 필터: Bilinear, 압축은 UI 무손실 우선. Android/iOS에서는 ASTC 4×4 또는 품질 검수 후 6×6
- 동일 계열 애셋은 캔버스, 피벗, 여백을 통일한다.
- 9-slice 리소스는 테두리 값과 최소 표시 크기를 메타 문서에 기록한다.
- 아틀라스 권장 분리: `UI_Common`, `Beggar`, `Estate`, `Combat_Hero`, `Combat_Boss`, `VFX`
- 이미지 내부에 한글, 가격, 스테이지 번호를 포함하지 않는다.

## 11. 검수 기준

- 390×844 실제 기기에서 금액, 초당 수익, 주요 버튼을 한눈에 읽을 수 있다.
- 홈과 전투 화면이 색조는 달라도 외곽선, 모서리, 아이콘 언어가 동일하다.
- 부동산 6개가 3×2 화면에서 겹치지 않고 가격/초당 수익과 함께 식별된다.
- 잠금/미구매/보유 상태가 색각에 의존하지 않고 형태와 아이콘으로도 구분된다.
- 구매 순간 빈 부지가 완성 건물로 바뀌어 소유감을 전달한다.
- 모든 거지 표정 교체 시 캐릭터 크기와 발 위치가 흔들리지 않는다.
- 4~5성 영웅은 작은 카드에서도 1~3성과 즉시 구분된다.
- 워터마크, 잘린 외곽선, 불규칙한 손가락/창문, 녹은 형태 등 생성형 이미지 흔적이 없다.
- 모든 이미지에 텍스트가 굽혀 있지 않고 다국어 UI 교체가 가능하다.
